# 🎟️ SmartPass Platform

**SmartPass** is an end-to-end, cryptographically secure event ticketing platform designed to eliminate ticket fraud and provide a seamless experience for attendees, organizers, and gatekeepers. 

Instead of relying on simple, easily cloned QR codes, SmartPass uses **Ed25519 asymmetric cryptography** to generate and sign highly secure, hard-to-forge PDF tickets. The platform features a robust micro-app architecture consisting of an attendee portal, a comprehensive admin dashboard, a dedicated scanner application, and a high-performance Python backend.

---

## ✨ Key Features

- **🛡️ Cryptographically Secure Tickets**: Every ticket is signed using an Ed25519 private key. The resulting QR code contains a verifiable cryptographic payload, meaning fake or duplicated tickets are instantly rejected at the gate, even offline.
- **📄 Dynamic PDF Generation**: The backend automatically generates premium, branded PDF tickets containing both cryptographic QR codes and traditional barcodes (`pdf417`), ensuring compatibility with all scanning hardware.
- **🌐 Triple-Frontend Architecture**: 
  - **Event Portal**: A modern, animated interface for attendees to discover events and purchase tickets.
  - **Admin Dashboard**: A secure portal for event organizers to manage events, track revenue analytics, and oversee users.
  - **Scanner App**: A specialized, lightweight web app designed for gate staff to scan QR codes via device cameras and instantly verify ticket signatures.
- **🚀 Automated Deployment**: Includes a complete suite of custom PowerShell scripts (`deploy/` directory) for automated environment checks, database initialization, and zero-downtime deployments for both the backend and all three frontends.

## 🛠️ Tech Stack & Architecture

### Backend (Core API & PDF Engine)
- **Framework**: Python, FastAPI
- **Database**: PostgreSQL with SQLAlchemy ORM
- **Authentication**: JWT (JSON Web Tokens), bcrypt password hashing
- **Cryptography**: `cryptography` (Ed25519), `python-jose`, RSA
- **PDF/Image Engine**: `ReportLab`, `Pillow`, `python-barcode`, `qrcode`, `pdf417gen`

### Frontends (React Ecosystem)
- **Frameworks**: React 18, Vite
- **Routing & Networking**: React Router, Axios
- **Styling & Animation**: Tailwind CSS, Framer Motion, Heroicons
- **Data Visualization**: Recharts, Chart.js

## 🔐 The Security Model (How it works)

1. **Purchase**: When a user buys a ticket, the backend generates a unique ticket payload (Event ID, User ID, Timestamp).
2. **Signature**: The payload is hashed and cryptographically signed using the server's highly secure `Ed25519` Private Key.
3. **Encoding**: The signature and payload are encoded into a high-density QR code and embedded into a premium PDF.
4. **Verification**: At the gate, the Scanner App reads the QR code and uses the corresponding Public Key to instantly verify that the ticket was generated by the SmartPass backend and hasn't been tampered with.

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- Node.js 18+ & npm
- PostgreSQL

### Local Setup

**1. Clone the repository**
```bash
git clone https://github.com/MarvinVutshila/smartpass-platform.git
cd smartpass-platform
```

**2. Start the Backend**
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Or `venv\Scripts\activate` on Windows
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

**3. Start the Frontends**
Open three separate terminal windows and run the following in each respective directory (`frontend/admin-dashboard`, `frontend/event-portal`, `frontend/scanner-app`):
```bash
npm install
npm run dev
```
